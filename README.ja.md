FINAL FANTASY XIII-2のPC版(Steam版)で、RTAを練習しやすくする機能を搭載したModです。

## 動作環境

- Windows
- Steam(PC)版FINAL FANTASY XIII-2
  - リージョンは問わない見込みですが、日本版以外は未確認です。  
    Steamのゲーム設定が日本語であればModの表示も日本語、それ以外の言語では英語になります。  
    開発・動作確認は日本版で行っています。海外版での動作報告も歓迎します。

## 使い方

1. zipファイルをダウンロードする

[**こちらのページの`FF13-2-SpeedrunPractice-vx.x.x.zip`をクリックしてください**](https://github.com/a-ki-yoshi/FF13-2-SpeedrunPractice/releases)。

2. zipファイルを展開し、`LICENSE`と`README`以外の3つのファイルを`ffxiii2img.exe`と同じフォルダ内に置く

フォルダのパスの例: `C:\Program Files (x86)\Steam\steamapps\common\FINAL FANTASY XIII-2\alba_data\prog\win\bin\`

| ファイル名| 説明 | 
| ---- | ---- |
| `dinput8.dll` | Mod本体 |
| `ff13-2-practice.bat` | Modありで起動するためのバッチファイル。詳細は「タイム計測時の注意事項」にて |
| `ff13-2-run.bat` | Modなしで起動するためのバッチファイル。詳細は「タイム計測時の注意事項」にて |

3. ゲームを起動する

4. 各種機能をホットキー入力で使用する(**F1キーで全ホットキーと設定を説明付きで表示し、その場で変更もできます**)

※設定ファイル(`ff13-2-srpractice.ini`)は同梱していません。「ホットキーと設定」の画面で設定を変えたときに、`ffxiii2img.exe`と同じフォルダに作られます。  
※なんらかの事情でF1キーが無効の場合は、メモ帳などで下の2行を入力し、`ff13-2-srpractice.ini`というファイル名で保存し、dllファイルと同じ場所に設置してください(`Ctrl+1`の部分には、F1の代わりに使いたいキーを書きます)。

```ini
[hotkeys]
help = Ctrl+1
```

※Modを更新する(別のバージョンを導入し直す)場合は、新しいzipの中身を同じように上書きで置いてください。iniファイルは同梱していないので、設定はそのまま残ります。

## タイム計測時の注意事項

Speedrun.comでは、ゲームやカテゴリーごとに許可されていないModの使用はルールで禁止されています。  
Speedrun.comなどに提出するためのタイム計測時には、このModを使用しないでください。  
**このModは、導入しているだけで一部の動きが変わります**(既定でONの「ロード時のヒストリアクロス省略」「ロード直後のあらすじ省略」、セーブ一覧に足す保存場所の行)。  
計測時は、下記のバッチファイルなどを使って、Modなしの状態で起動してください。

### 計測などの時にはMod自体を使えないようにしたい場合

計測などの時にMod自体を使えないようにしたい場合は、同梱の2つのbatファイル(バッチファイル)からゲームを起動するとスムーズです。  
`ff13-2-run.bat`: ModなしでFF13-2を起動  
`ff13-2-practice.bat`: ModありでFF13-2を起動  
- `dinput8.dll`のファイル名を無効なファイル名(`dinput8.dll.off`)に変えたり戻したりして、Modの有効/無効を切り替えています
- 「セーブ枠の上限」を41以上にしている場合、セーブデータ41以降があるとModなしのゲームはセーブ一覧で終了してしまうため、`ff13-2-run.bat`は起動前にセーブフォルダの`ff13_2-NN.dat`を`ff13_2-NN.dat.parked`に改名して、ゲームが読まないようにします
  - `ff13-2-practice.bat`で起動するか、手動でファイル名を`dinput8.dll`に戻してゲームを起動すると、Modが`.parked`を外して元の名前に戻します
- 「ホットキーと設定」の画面の「Modなし起動で使うカテゴリー」でカテゴリーを選んでおくと、`ff13-2-run.bat`はそのカテゴリーのセーブデータ1〜40をセーブ一覧に表示します
- Modなしで起動中に作ったセーブデータは、次にModありで起動した後もそのカテゴリーのデータとして保持されます
- 2回続けて実行しても状態は変わりません
- ゲームの起動中は使えません(先に終了してください)
- batファイルを使わず、手作業でdllファイルを退避したりファイル名を変えたりしても構いません。その場合、セーブデータ41以降があるなら、それも退避してください
- batファイルは、ショートカットを作成してそちらをクリックしても実行できます
- batファイル名は、拡張子以外の部分を変更できます

## 他のModとの併用

  - 同梱のbatファイルは、このMod以外の`dinput8.dll`(FPS Fixなど)が置かれているときは、ファイル名を変えずに止まります
- Drop Mod(Nekton and Gahongas Drop Rate Mod)とは併用可能です。Mod自体もbatファイルもDrop Modには干渉しません。

## ホットキー概要

- 各機能にはホットキーが割り当てられています
- F1キーで、各機能と現在のホットキー、全設定を並べた「ホットキーと設定」の画面をゲーム画面に表示できます。その画面で変更もできます

## 機能

ON/OFFを切り替える機能は、ゲームを再起動してもON/OFFの設定が引き継がれます。

### ホットキーで使う機能

(\[ \] 内はホットキーの初期値です。)

- **\[F1\] ホットキーと設定**
  - 「ホットキーと設定」の表示ON/OFFを切り替える
  - ↑ ↓キーで行を選ぶ
  - ホットキーを変えるには、その行で決定してから新しいキーを押す(Ctrl・Shift・Altとの組み合わせも可)。同じキーをもう一度押すと解除
  - 既に他の機能に割り当てられているキーは使用不可
  - 変更された値はすぐ有効になる
  - 設定を保存する`ff13-2-srpractice.ini`ファイルが未作成であれば作られ、該当する行だけが書き換えられる
  - 切り替えできる機能
    - 他のウィンドウ操作中もホットキー有効(既定: OFF)
      - OFFのときは、ゲームのウィンドウがアクティブなときだけホットキーの入力を受け付ける
      - ONにすると、アクティブでないときも有効
    - セーブ枠の上限(既定: 40)
      - **この機能を使う場合は、このゲームのSteamクラウド同期をOFFにしてください**
      - セーブ枠の上限を99まで増やせる
    - オートセーブ用のスロット固定(既定: **OFF**)
      - オートセーブ時に最終番号のスロットを上書き先にして、ロードしたセーブデータが上書きされないようにする
      - オートセーブ用スロットの中身は上書きされるので注意
    - 上書きセーブ時にメモを残す(既定: **OFF**)
      - 「セーブデータの整理」でメモを登録したスロットに上書きセーブすると、ONならメモが残り、OFFなら消える
    - Modなし起動で使うカテゴリー(既定: なし)
      - **この機能を使う場合は、このゲームのSteamクラウド同期をOFFにしてください**
      - `ff13-2-run.bat`を使ってModなしで起動したときに、セーブ一覧に表示するカテゴリーを選ぶ(詳細は「タイム計測時の注意事項」にて)
      - なし: 使用中のカテゴリーのまま(セーブデータ41以降だけ隠す)
    - ロード時のヒストリアクロス省略(既定: ON)
      - エリア内でセーブしたデータは、そのエリアのセーブ位置へ直接ロードされる
      - ヒストリアクロスへは、ポーズメニューの「ヒストリアクロス」からいつでも移動できる
      - ヒストリアクロスでセーブしたデータや、このModを入れる前に作ったもの・外から持ち込んだファイルは、これまでどおりヒストリアクロスへロードされる
    - ロード直後のあらすじ省略(既定: ON)
      - ロードの直後に流れる「これまでのあらすじ」ムービーを省略する
    - 「GAME SPEED」の倍率設定(既定: 3.0)
      - 下の「GAME SPEED」で切り替える倍率を設定できる
      - 「ホットキーと設定」の画面で、0.5/1.5/2/3/4/5/6/8/10の中から最大8個まで登録できる(iniに直接書けば0.1〜10の任意の値も可)
      - 例えば3と8を登録した場合、ホットキーを押すごとに3倍→8倍→OFFのように順番に切り替わる
    - 文字サイズ(既定: 100%)
      - このModが画面に表示する文字(ONになっている機能の表示、戦闘オーバーレイ、各メニュー)の大きさを変えられる
      - 「ホットキーと設定」の画面で、自動/75%/100%/125%/150%/175%/200%/250%/300%から選べる(iniに直接書けば0.5〜4の任意の値も可)
      - 100%が従来の大きさ。自動は画面の解像度に合わせて大きくする(720pで100%、1080pで150%、4Kで300%)
      - 変更はすぐ反映される。「ホットキーと設定」の画面が画面に収まらないときは、選択中の行に合わせてスクロールする
    - ログレベル(既定: normal)
      - ログ出力の詳細度を設定できる
      - ログはゲーム起動ごとに新しくなり、1回前の分だけが`prev.log`に残るので注意
      
- **\[F2\] GAME SPEED**
  - ゲームの速度を変更する。フィールド移動、戦闘、ATB速度など全体的に変わる
  - ONの間は画面に`(F2) GAME SPEED 3x: ON`のように表示される

- **\[F3\] KILLモード**
  - ホットキーで「戦闘開始時に即勝利 + 一撃必殺」→「一撃必殺」→OFFの順番に切り替えられる
    - **戦闘開始時に即勝利**
      - 戦闘中にONにしても、既に始まっている戦闘には無効。次の戦闘開始時から有効
      - 戦闘が始まると同時に勝利で終わる
      - アイテムやCPは、確定ドロップのもの以外は入手できない
      - 即勝利で空にした戦闘は、「戦闘オートリスタート」の対象にならない
    - **一撃必殺**
      - ダメージを与えた瞬間にその敵のHPが0になる
      - アイテムのドロップ仕様は、通常の戦闘と同じ
  - ONの間は画面に`(F3) 戦闘開始時に即勝利 + 一撃必殺: ON`のように表示される

- **\[F5\] 敵の出現を抑止**
  - フィールド移動中に敵が出現しなくなる
  - ONの間は画面に`(F5) 敵の出現を抑止: ON`と表示される

- **\[F6\] 戦闘オートリスタート**
  - ONにすると、敵を全滅させても勝利にならず、リスタートされる
    - リスタートで戦闘を始め直すボス戦では、同じ戦闘がもう一度始まる
    - オープニングのボス戦は2連戦で、従来のリスタートでは2戦目からでも1戦目に戻るが、オートリスタートでは2戦目から始まる
    - **敵のHPを削り切った後にムービーが始まるタイプの戦闘では無効**。手動でリスタートしてください
  - ONの間は画面に`(F6) 戦闘オートリスタート: ON`と表示される

- **\[F7\] どこでもセーブ**
  - **この機能を使う場合は、このゲームのSteamクラウド同期をOFFにしてください**
  - フィールドで、ヒストリアクロスのセーブと同じようにスロット選択画面を開ける
  - 正常に使えるのはフィールドだけ。ヒストリアクロスでは従来のセーブ画面を開いてセーブしてください
  - イベント中などに押すのを止める仕組みは無いので、ホットキーを押してしまったらスロット選択画面でキャンセルすること(もう一度ホットキーを押してもキャンセルにはならない)
  - フィールドでのポーズメニューからの「セーブをする」は従来どおりの仕様(最後にセーブ/ロードしたスロットへ無言で上書き)

- **\[F9\] セーブデータの整理**
  - **この機能を使う場合は、このゲームのSteamクラウド同期をOFFにしてください**
  - 操作
    - 選択中の項目を決定: Enter
      - このメニューの表示中は、キーボードでゲームを操作できないようにしているので、ゲームの決定キーと重なっていても安全
    - 項目を選ぶ: ↑ ↓キー
    - 値を変える: ← →キー
    - セーブ一覧で操作対象のセーブを選ぶ: A Dキー
    - テキスト入力: 各種キー
    - テキスト文字削除: Backspace
  - タイトル画面と、セーブ一覧でのみメニューを表示する
  - それぞれの画面で表示されるメニューは異なる
  - タイトル画面で使える機能
    - セーブデータ一覧に表示する範囲
      - ロード用のセーブ一覧で表示するエリアのフィルター
      - 「サンレス水郷 AF300」のような、一覧の3行目と同じエリア+年代ごとに絞り込める
      - ヒストリアクロスで保存したものは、選択されているエリアとして扱われる
      - エリアの選択肢は、各エリアで一番早いセーブの順に並ぶ
      - このModを入れる前のセーブや、Modなしで保存したセーブにも有効
      - NEW GAMEのあと最初に保存したセーブは、`ヴァルハラ`に該当する
      - 設定は保存されるので、ゲームを再起動したときも同じエリア設定のままになる
    - カテゴリー管理
      - セーブデータの一式をフォルダ単位で切り替える機能
        - 使用中のカテゴリーはこれまでどおりセーブフォルダ直下にあり、それ以外は`{セーブフォルダ}\categories\{カテゴリー名}\`に退避される
      - カテゴリー機能を未使用だと、「main」という名前のカテゴリーを選択中の状態として扱われる
      - 1カテゴリーには、セーブ枠の上限の数(通常40)までセーブデータが入る
      - 詳細な機能
        - 「{切替先}に切替(使用中: {カテゴリー名})」
          - ←→キーを押して切替先を選ぶ。決定キーを押す/別の行を選択する/ホットキーでメニューを閉じる のいずれかで切り替わる
          - 最初の`----`は未選択で切り替えなしの状態
        - 新しいカテゴリーを作って切替(最新の1件をコピー / 全件コピー)
          - カテゴリー名を入力し、新カテゴリーへ切り替える
          - 「最新の1件をコピー」: 最新のセーブ1件だけをコピーする(0件のカテゴリーはタイトル画面の「つづきから」が消えるため)
          - 「全件コピー」: 使用中のカテゴリーの全セーブを、番号も含めてそのままコピーする
          - 入力欄について
            - 半角文字はそのまま入力できる
            - 別の場所でコピーしておいたテキストをCtrl+Vで貼り付けることもできる
              - その場合は、全角、カナなどのマルチバイト文字も可
            - 最大24文字
            - `\ / : * ? " < > | ,`は使えない
            - Backspaceで1文字ずつ削除可能
            - 既存のカテゴリーと同じ名前は決定できない(入力欄に赤字でエラーが出る)
            - Enterで決定、ホットキーでキャンセル
        - 使用中のカテゴリーの名前を変更
        - 「{カテゴリー名}」を削除
          - ←→キーを押して削除するカテゴリーを選び、決定で削除
          - セーブが1件以上あるカテゴリーは、確認のためもう一度決定が必要
          - 使用中のカテゴリーは選べない。消したいときは先に別のカテゴリーへ切り替えること
          - 中身ごとWindowsのごみ箱に入るので、間違えたときはごみ箱から戻せる
            - ごみ箱の無いドライブ(ネットワークやリムーバブル)にセーブフォルダを置いている場合は、そのまま削除される
      - 直行ロードの記録も、セーブデータと一緒に移動する
      - 切替中にクラッシュや電源断で中断された場合は、次回起動時に自動で完了する。それが終わるまで、セーブを動かす操作・消す操作は受け付けない
    - 並び順
      - ← → でゲームのセーブ一覧の表示順を選ぶ: セーブ日時順/進行順(終盤が先頭)/進行順(序盤が先頭)/セーブ番号順
      - 進行順では、同じ場所のセーブはその場所での物語の進み具合で並べて、プレイ時間はその次に見る
      - どの並び順でも、オートセーブ用スロットが先頭に来る(一覧の見出しは`(AUTO) セーブデータ NN`)
      - セーブ一覧の日時表示は実際の保存日時のまま変わらない
      - 選んだ並び順は記憶され、変更するまでどの一覧もその順で出る
    - 進行順に再採番する
      - 使用中のカテゴリー内のセーブデータを、ストーリー進行順(進行が同じデータは日時の古い順)に再採番する。セーブデータ01が物語のいちばん手前になる
      - 1回決定を押すと確認メッセージが表示され、もう一度決定すると実行される
      - リネーム中にクラッシュや電源断で中断された場合は、次回起動時に自動で完了するか、元の番号に戻す
  - セーブ一覧画面で使える機能(カーソルを合わせている項目ごとに利用可能)
    - メニューはそのカーソルに追従する: メニュー表示中もゲームパッドやA/Dキーのカーソル移動で対象のセーブへ切り替わる
    - ホットキーを押すと閉じる。Backspaceでは閉じない(ゲーム自体がそのキーを「キャンセル」と認識するため)
    - メモ
      - 入力したテキストを、ゲームのセーブ一覧に表示できる
      - 「セーブデータ 39 - メモ」のように、見出し行の末尾に付く
      - 入力欄について
        - 半角文字はそのまま入力できる
        - 別の場所でコピーしておいたテキストをCtrl+Vで貼り付けることもできる
          - その場合は、全角、カナなどのマルチバイト文字も可
        - 最大24文字
        - Backspaceで1文字ずつ削除できる
        - Enterで決定、ホットキーでキャンセル
      - メモはセーブファイル自身に書かれるので、ファイルに付いて回る(オートセーブ用スロットへの複製にも残る)
      - セーブデータを上書き保存した場合
        - 「ホットキーと設定」画面の「上書きセーブ時にメモを残す」をONにすると、保存のたびにModがメモを書き戻して残す
        - OFFの場合は、メモも消える
        - ただし、オートセーブ用スロットへのオートセーブでは、設定にかかわらずメモが消える
    - 別カテゴリーへ送る(「コピー」「移動」の行)
      - セーブデータ1件、または範囲選択した分をまとめて「コピー」または「移動」できる
      - ←→キーで送り先のカテゴリーを選ぶ。選んだ先は「コピー → {カテゴリー名}」と表示する
      - 「<新しいカテゴリー>」を選ぶと、名前を付けて新しいカテゴリーを作れる
      - 送り先ではそのカテゴリーの空き番号に入る
      - 送り先の空き番号が範囲の件数に足りないときは、何もせずにその旨を表示する
      - 「移動」では、使用中のスロットとオートセーブ用スロットは対象外になる(そのまま残り、その旨が表示される)。「コピー」なら送れる
      - 「移動」した後も、セーブ一覧を開いたままだと元のセーブデータが残って見える
        - 選んでもロードに失敗したと出るだけで問題は発生しない
        - セーブ一覧を開き直すと消える
      - 「移動」で移動元のセーブデータが0件になった状態でタイトル画面に戻ると、「つづきから」が消えるので注意
    - 範囲選択
      - 「範囲選択(セーブデータNを始点にする)」を実行すると、そのセーブが範囲の一方の端になる
      - ゲームのカーソルをゲームパッド操作またはA/Dキーでもう一方の端に合わせると、範囲を選べる
      - エリアの絞り込み中は、表示されている項目だけが対象
      - 同じ行をもう一度実行するか、セーブ一覧画面を離れると、選択を解除できる
    - 削除
      - 範囲選択した分のセーブデータをまとめて削除する
      - 範囲を選んでいないときは実行できない
      - 1回目の決定で行が確認メッセージに変わり、もう一度決定すると実行される
      - 行から離れたとき、カーソルを別のセーブデータへ動かしたとき、メニューを閉じたとき、範囲選択を解除したときは、確認が解除される
      - セーブデータはWindowsのごみ箱へ送られるので、間違えてもごみ箱から戻せる
        - ごみ箱の無いドライブ(ネットワークやリムーバブル)にセーブフォルダを置いている場合は、そのまま削除される
      - 「移動」と同じく、使用中のスロットとオートセーブ用スロットは残る
      - セーブ一覧を開いたままだと削除した行が残って見える。一覧を開き直すと消える
      - カテゴリー内のセーブデータが0件になると、タイトル画面から「つづきから」が消えるので注意

- **\[F10\] 戦闘オーバーレイ**
  - 戦闘中に下記を表示する
    - TIME
      - GAME: ゲーム内時間
      - REAL: 実時間
      - ATB \*\*s: パラダイムのシフトで味方全員のATBが全回復するまでの残り秒数(READY = 次のシフトで全回復する)
    - TARGET
      - HP: ターゲットの残りHP
      - ATB: ターゲットのATBゲージの値
      - CHAIN: ターゲットのチェーンゲージの持続時間。100%に戻るまでの残り秒数
  - 「GAME SPEED」機能と併用する場合は、GAME(ゲーム内時間)もその速度で進む。REALは変わらない

### 常に有効な機能

- **セーブ一覧に保存した時のエリアを表示**
  - セーブ一覧の各データの最終行に、保存した時のエリアが表示される
    - エリア内で保存したデータ: `新都アカデミア AF500`のようにエリア名と年代が表示される
    - ヒストリアクロスで保存したデータ: `ヒストリアクロス(新都アカデミア AF500)`のようにカーソルが乗っていたエリアが表示される
    - NEW GAMEのあと最初に保存したデータ: `ヴァルハラ`と表示される
  - このMod導入前に作られたセーブには、一度保存し直すまで表示されない

## 自動生成されるファイル

- `ff13-2-mods\`フォルダおよびその中の各種ファイル
  - 初回起動時に作成(ログ、状態、直行ロードの記録、カテゴリー名など)
- `ff13-2-srpractice.ini`
  - 「ホットキーと設定」の画面で設定を変えたときに、`ffxiii2img.exe`と同じフォルダに作成
- `{セーブフォルダ}\categories\`
  - カテゴリーを作ったときに作成。使用中でないカテゴリーのセーブデータ本体が入っている
- `{セーブフォルダ}\ff13_2-NN.dat.parked`
  - `ff13-2-run.bat`がセーブデータ41以降(「Modなし起動で使うカテゴリー」を選んでいるときは全部)を改名したもの。Modの起動で元に戻る
- `ff13-2-srpractice.nomod`
  - 「Modなし起動で使うカテゴリー」で選んだカテゴリー(使用中のカテゴリーなら`ff13-2-mods\`)内に置かれる

## 不具合やクラッシュが起きたとき

できれば、下記の対応をお願いします。

### 1. ログの退避(コピー)

まず、`ff13-2-mods\ff13-2-srpractice.log`をデスクトップなど別の場所へコピーしてください。

> **注意: ゲームを起動し直すと、このログは`ff13-2-mods\prev.log`に移って新しいログが始まり、その次の起動で`prev.log`も上書きされます。**
> 2回起動する前にコピーしてください(落ちた直後のログが唯一の手がかりです)。ゲームが落ちた場合、Modは落ちた場所もこのログに書き残そうとします。

### 2. `verbose`での再現

再現できる場合は、「ホットキーと設定」の画面の「ログレベル」を`verbose`に変更してから、同じ操作をして症状を再現させてください。
原因を特定しやすくなります。再現できたら、そのログも同じように退避してください。

### 3. ログの送付

症状(何をしたら何が起きたか)と、退避したログを添えてご連絡くださると、大変助かります。

## アンインストール

- アンインストールはインストールフォルダから`dinput8.dll`を削除するだけ
- 自動生成されるファイルやディレクトリも削除して問題ありません
  - **例外: セーブフォルダの`categories\`フォルダには、使用中でないカテゴリーのセーブデータ本体が入っています。** 削除する前に、必要なセーブを`categories\`の外(セーブフォルダ直下)へ移すか、フォルダごとバックアップしてください
- **「セーブ枠の上限」を41以上にしていた場合は、先にセーブデータ41以降を1〜40の空き番号へ移すか、セーブフォルダの外へ出してください。** 残したままだと、Modなしのゲームはセーブ一覧を開いた瞬間に終了します
- `ff13-2-run.bat`で起動した後は、削除する前に一度Modありで起動してください。`ff13-2-run.bat`が隠したセーブデータ(`.parked`)は、Modの起動で元に戻ります
